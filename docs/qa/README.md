# Evidencia de comprobaciones

Este directorio conserva resultados de pruebas, capturas y manifiestos para verificar afirmaciones concretas. Cada entrega se interpreta con su fecha, entorno y alcance. Una ejecución local anterior no demuestra el comportamiento del VPS actual.

| Área                             | Punto de entrada                                                                                                                                                                                               | Qué permite comprobar                                                                     |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Fuentes, RAG y proveedores       | [Aceptación RAG](rag/acceptance.md)                                                                                                                                                                            | Archivos y formatos ensayados, recuperación, modelos consultados y pendientes declarados. |
| Interfaz administrativa y widget | [Aceptación frontend](frontend/acceptance.md)                                                                                                                                                                  | Recorridos, temas, integración, capturas y comprobaciones manuales pendientes.            |
| Métricas e interfaz              | [Resultados de métricas](frontend/metrics/live-contract.json)                                                                                                                                                  | Contrato y resultados del caso registrado en ese conjunto de pruebas.                     |
| Memoria, Preview y Vertex        | [Acta de aceptación](conversation-memory-acceptance.md) y [muestra de latencia](conversation-memory-latency-2026-10-16.json)                                                                                   | Aislamiento, contexto visible, modelos, latencias observadas y pendientes externos.       |
| Sesión, autorización y errores   | [Revisión de seguridad](security-review-2026-10-16.md)                                                                                                                                                         | Controles comprobados, límites de abuso y condiciones aún pendientes del VPS.             |
| Dependencias y herramientas      | [Actualización y reversión](dependency-update-2026-10-16.md), [auditoría de producción](dependency-audit-production-2026-10-17.json) y [auditoría de desarrollo](dependency-audit-development-2026-10-17.json) | Inventario, clasificación de avisos, imagen standalone y regresiones críticas.            |
| Documentación y diagramas        | [Revisión documental](documentation-review-2026-10-17.md)                                                                                                                                                      | Aplicación de Diátaxis, C4 y Mermaid; enlaces locales y desviaciones corregidas.          |
| Auditoría técnica integral       | [Auditoría del 18 de octubre](technical-audit-2026-10-18.md)                                                                                                                                                   | Riesgos priorizados, controles aprobados y condiciones de cierre antes del VPS.           |
| Límite de infraestructura        | [Límites observados](infrastructure-boundaries.json)                                                                                                                                                           | Evidencia del entorno en el que se ejecutó la comprobación.                               |
| Recomendaciones de tesis         | [Línea base](recommendations/baseline-2026-10-13.md), [guardrails](recommendations/guardrails-review-2026-10-13.md) y [validación del 15 de octubre](recommendations/validation-2026-10-15.md)                 | Casos reproducibles, límites de las comprobaciones y riesgos pendientes de IA.            |

Los archivos JSON, imágenes y reportes HTML son evidencia asociada a esos puntos de entrada. No son manuales de instalación, requisitos nuevos ni configuración para producción. Conservar las limitaciones y los fallos junto a los resultados; no reemplazar una ejecución pasada con otra distinta.
